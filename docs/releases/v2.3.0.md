# Wisp 2.3.0 / VS Code companion 1.14.13

## Flight in the terminal

The Flight home screen and command views adapt as you resize the terminal. Pickers keep the current selection visible, and headings, values and help text follow the light or dark terminal theme.

In `/routing`, each route name sits alongside its destination, including when a long alias wraps. After choosing a target, press Enter to apply it or Esc to revise it. Bridge setup groups the client commands and lets you expand manual Advisor instructions when you need them.

The home screen and command headers show the active Bridge port. Flight can also recognize another Wisp host on the configured loopback port without sending credentials. Quitting the terminal leaves a separately hosted Bridge running.

## Surfaces

- **Terminal and npm 2.3.0** include Flight. The npm shell pins its four platform packages to the same version.
- **VS Code companion 1.14.13** bundles the shared Bridge with its new listener-port accessor. The Flight screens belong to the terminal.
- **wisp-slot 1.7.6** and **Desktop protocol 5** retain their existing versions.
