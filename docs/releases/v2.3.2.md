# Wisp 2.3.2

- **The Claude alias picker is back.** Normal `claude-wisp` sessions discover your Wisp aliases and let you switch with `/model`. `--model Astra` chooses a starting alias without pinning the conversation.
- **Exact context budgets are opt-in.** Use `claude-wisp --exact-context --model Astra` to retain the signed, one-target profile. Change exact-mode targets by exiting and resuming with an explicit alias and the same flag.
- Normal mode uses Claude Code's context estimates, not a promise of each backend's real capacity. It may compact early or exceed a smaller provider's window. Exact mode keeps its switch/fallback guards; it does not guarantee full-window provider acceptance.
- Native resume and fallback work in normal mode. A normal launch nested inside an exact session clears the inherited Wisp profile and budget. Real settings, credentials, permissions and routing are preserved.
- The README and launcher guide explain both modes. Relaunch Claude Code through the updated `claude-wisp` command to use the restored picker; installing an update does not replace an already-running process.

## Surfaces
