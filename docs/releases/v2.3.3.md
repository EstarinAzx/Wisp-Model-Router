# Wisp 2.3.3

When Antigravity returns HTTP 429 with `RESOURCE_EXHAUSTED` and no retry time, Wisp now returns the error after one provider request. Previously, Wisp could send six requests before returning the 429, and Claude Code could start another retry cycle. The Messages response now tells Claude Code to stop retrying an untimed Antigravity 429.

The generic provider response does not identify which limit was reached. Wisp now says so and links to [Google's guidance for third-party clients](https://antigravity.google/docs/faq). Wisp continues to honor explicit retry timing from the provider.

## Surfaces

Terminal/npm **2.3.3** and VS Code companion **1.14.16** both include the shared Bridge fix. Restart the terminal Bridge or reload the VS Code window that hosts it after installing the update.
