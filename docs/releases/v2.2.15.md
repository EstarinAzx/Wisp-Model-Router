# Wisp 2.2.15 / VS Code companion 1.14.12

This patch removes conflicting authentication from Claude launches and makes Anthropic sign-in failures explicit instead of presenting them as retryable gateway errors.

## Fixes

The Claude launcher now clears the competing `ANTHROPIC_AUTH_TOKEN` in the child environment and temporary settings while retaining local Bridge API-key authentication. Inherited token values are neutralized, and explicit settings cannot reintroduce a conflicting token. Global settings and stored credentials are not changed.

After a failed Anthropic token refresh, already-expired credentials are rejected before inference. A still-valid token remains usable if an early refresh fails. Trusted upstream HTTP 401 responses and local expired-credential failures now become actionable authentication errors through Messages, Chat Completions and Responses. Signed Desktop failures retain their redacted error format.

## Verification and limits

The implementation passed 2,179 core tests, 219 terminal tests, core and terminal typechecks, and the VS Code build. Regression tests cover inherited/settings auth conflicts, failed refresh variants, credential preservation, all three Bridge APIs and signed Desktop classification. CodeRabbit reviewed all 11 implementation/test files with zero issues; the hosted PR check and all four platform builds passed. Release packaging and platform smoke checks are required before publication.

No live provider inference or credential refresh was used to validate the fix. An expired account can still require signing in through Wisp. This patch does not resolve Antigravity's separate upstream 429, restore exhausted quota, change routing or modify Antigravity retry behavior.

## Surfaces

- Terminal/npm and four platform packages: **2.2.15**, including the launcher and shared authentication-error fixes.
- VS Code companion: **1.14.12**, including the shared authentication-error fix.

Provider settings, stored credentials and permissions are preserved. Existing Bridge processes must restart to load an installed update.
