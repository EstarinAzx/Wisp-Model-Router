# Wisp 2.3.1

- Open `/guide` for a first-route walkthrough and chapters on providers, clients, routing, and troubleshooting. Commands and argument hints are color-coded in both terminal themes.
- The home and routing flames now animate. Set `WISP_REDUCED_MOTION=1` before launching Wisp to keep them still.
- Provider lists pin **Custom** first and sort the remaining entries by display name. Select a saved alias and choose **Change provider** to pick a new destination. **Rename alias** and **Remove alias** stay in the alias action menu.
- The Claude family binding action previews stable model IDs from models.dev. It updates the four family routes together when selected. An incomplete or unavailable catalog offers a retry and preserves saved routes.

## Surfaces

These changes are in the Wisp terminal and npm package. The VS Code companion remains at 1.14.13.
